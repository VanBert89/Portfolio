Premier site web

Ce projet était mon premier projet individuel en BTS : réaliser un petit site (en local) en HTML sur le sujet de mon choix. C'était ma toute première expérience avec le HTML.

Technologies utilisées

  • HTML : structure des pages
  • CSS : design et mise en forme
  • JavaScript : quiz et interactions

Jeu Zelda en Python

Création complète d'un script interactif en Python (« Jeu_Zelda.py ») réalisé en équipe. Il gère les déplacements, des combats textuels, divers événements et un système de sauvegarde / redémarrage, directement depuis le terminal.

Technologies utilisées

  • Python : modules natifs, conditions, boucles, gestion des entrées utilisateur

Interface de gestion d'inventaire

En stage, mes responsables m'ont confié le développement d'une interface de gestion de leur matériel informatique. À mon arrivée, ils n'avaient qu'un fichier CSV (Excel) ; ils disposent désormais d'une interface fluide et ergonomique reliée à une base de données.

Ce projet m'a permis de valider mon passage en deuxième année de BTS.

Technologies utilisées

  • HTML : interface
  • PHP : lien entre l'interface et la base de données
  • SQL : base de données
  • CSS : design
  • JavaScript : fonctionnalités et affichage

Interface de gestion du personnel

En intérim dans la même entreprise, j'ai développé une interface de gestion de l'ensemble du personnel. Le principe est proche de l'interface d'inventaire ; les différences portent sur les tables, les requêtes SQL et l'optimisation de l'ergonomie.

L'entreprise m'a gardé quatre semaines supplémentaires après mon stage pour mener à bien ce projet.

Technologies utilisées

  • HTML : interface
  • PHP : lien avec la base de données
  • SQL : requêtes optimisées
  • CSS : design
  • JavaScript : fonctionnalités

Portfolio web

Conception de ce site personnel, entièrement responsive, avec un thème clair / sombre, une structure sémantique, de bonnes pratiques SEO et un déploiement automatisé sur GitHub Pages via GitHub Actions.

Technologies utilisées

  • HTML : structure sémantique
  • CSS : Grid, Flexbox, media queries, variables
  • JavaScript : thème, menu, modales
  • GitHub Actions : validation et déploiement automatiques
