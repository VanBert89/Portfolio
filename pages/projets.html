Jeu Zelda (Python)

Description détaillée :

Ce projet consiste en la création complète d'un script interactif en Python (nommé "Jeu_Zelda.py"). Il gère les déplacements, des combats textuels, et un système de sauvegarde/redémarrage directement depuis le terminal en ligne de commande. Ceci était un projet en coopération de création d'un jeu interactif, diverses évènements et plusieurs fonctionnalités.

Technologies utilisées : Python (modules natifs, structures conditionnelles, boucles et gestion des entrées utilisateur).

Interface de gestion d'inventaire

Description détaillée :

En tant que stagiaire dans une entreprise, mes responsables m'ont confié la tâche de développer une interface de gestion de leur matériel informatique. Lorsque je suis arrivé, ils avaient juste un fichier .csv (excel) contenant les matériels, et maintenant grâce à mon passage ils ont une interface fluide et ergonomique pour renseigner un matériel dans leur Base De Données. Ce projet m'a permis de passer en 2ème année de BTS.

Technologies utilisées : HTML (Création du front-end du site), PHP (Mise en relation entre l'interface et la BDD), CSS (Design et mise en forme) et JS (Fonctionnalités et affichage).

Interface de gestion de personnel

Description détaillée :

En tant qu'intérimaire dans la même entreprise que le projet précedent, mes responsables m'ont confié la tâche de développer une interface de gestion de l'ensemble du personnel présent dans l'entreprise. Ceci étant presque le même principe que pour l'autre interface, ce qui différait était juste les requêtes SQL, les tables et l'optimisation sur l'interface. Globalement, les deux se ressemblent beaucoup. L'entreprise m'a gardé quatre semaines de plus après mon stage pour pouvoir effectuer cette tâche et renforcer mon expérience dans le domaine.

Technologies utilisées : HTML (Création du front-end du site), PHP (Mise en relation entre l'interface et la BDD), CSS (Design et mise en forme) et JS (Fonctionnalités et affichage).

Portfolio Web

Description détaillée :

Conception d'un site web personnel entièrement responsive. L'objectif était de structurer un portfolio moderne en utilisant HTML, CSS, les grilles et Flexbox, tout en assurant une compatibilité parfaite entre les écrans de PC et de smartphones.

Technologies utilisées : HTML, CSS (Media Queries, Flexbox, Grid).
